## About

NoteLyft is a full-stack web application for taking notes, organizing tasks, and staying productive. Users can register, log in, and create and manage their own notes. Built as a software development co-op project, with a focus on learning full-stack architecture end to end from the database, through a REST API, to a React frontend.

This project is being developed incrementally.

---

## Tech Stack

**Frontend:** React · JavaScript · HTML · CSS  
**Backend:** Java · Spring Boot · REST API  
**Database:** PostgreSQL  
**DevOps & Deployment:** Docker · Vercel (frontend) · Render (backend)

---

## Features

- User registration and login (authentication)
- Create, read, update, and delete notes (CRUD)
- Notes with title, content, dates, and tags
- Each user has their own private notes
